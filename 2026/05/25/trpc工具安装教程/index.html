tRPC 工具安装教程

发表于2026-05-25|更新于2026-05-25|后端开发
|浏览量:

tRPC 是腾讯开源的高性能 RPC 框架。本文介绍两个核心工具的安装：trpc-cmdline（项目脚手架和代码生成）和 trpc-cli（服务调试和接口测试）。

环境准备

安装 Go

tRPC 工具基于 Go 生态，需要 Go 1.18 以上版本。

未安装的话去 go.dev/dl 下载 Windows 安装包，一路 Next 即可。

安装 protoc

tRPC 使用 Protobuf 作为接口定义语言，需要 protoc 编译器。

未安装的话：

  1. 打开 Protobuf Releases
  2. 下载 Windows 版本，例如 protoc-28.x-win64.zip
  3. 解压到 C:\protoc
  4. 将 C:\protoc\bin 加入系统环境变量 PATH
  5. 验证：protoc --version

安装 trpc-cmdline（脚手架工具）

trpc-cmdline 提供 trpc 命令，用于创建项目模板和生成 tRPC 代码。

方式二：下载预编译二进制

如果网络受限无法用 go install，可以直接从 GitHub 下载：

  1. 打开 trpc-cmdline Releases
  2. 下载 Windows 版本的 .exe 文件
  3. 放到 C:\Users\你的用户名\go\bin\ 目录下
  4. 确保该目录在系统 PATH 中

基本使用

参数 说明
-func 接口路径，格式 /包名.服务名/方法名
-target 目标地址，ip://IP:端口
-body 请求体 JSON
-timeout 超时时间，单位毫秒
